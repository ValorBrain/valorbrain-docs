Pacote: [`@valorbrain/cli`](https://www.npmjs.com/package/@valorbrain/cli) `0.1.0`.
Alias do proxy stdio de MCP: [`@valorbrain/connect`](https://www.npmjs.com/package/@valorbrain/connect).

```bash
npx @valorbrain/cli help --json
```

Aquele JSON é o contrato. Se um blog post ou README citar um subcomando que
não está nesse objeto, o comando não existe.

## Flags globais

| Flag | Alias | Significado |
|---|---|---|
| `--json` | `--agent` | Um único objeto JSON no stdout, sem cor, sem spinner |
| `--key` | | Sobrescreve a chave de API (senão `~/.valorbrain/config.json`) |
| `--url` | | Sobrescreve a URL base REST |

Padrões:

- REST: `https://valorbrain-api.valor.digital`
- MCP: `https://mcpbrain.valor.digital/mcp`
- Config: `~/.valorbrain/config.json`

## Comandos

### `init --agent [--agent-caller <platform>]`

Cria um shadow tenant e uma chave `vb_agent_`. Veja o [Começo rápido](/docs/quickstart).

### `init --email <address> [--otp <code>]`

Vincula a chave existente a um email via OTP. A chave não muda.

### `identify <platform>`

Backfill idempotente de `agent_caller`. Autodeclarado, nunca inferido do ambiente.

### `add <text>` / `--file <path>`

Armazena um documento.

| Flag | Mapeia para |
|---|---|
| `--collection <name>` | `collection` (o padrão depende do servidor; passe um se fizer diferença) |
| `--title <t>` | `title` |
| `--type <t>` | tipo de conteúdo (`decision`, `observation`, `problem`, `lesson`, `milestone`, `handoff`, `note`) |

Chama `POST /documents`. O body é armazenado verbatim — sem tradução.

### `search <query>`

| Flag | Significado |
|---|---|
| `--collection <name>` | Restringe a uma coleção |
| `--mode auto\|keyword\|semantic\|hybrid` | Modo de recuperação |

Chama `POST /search` com `compact: true`.

### `list`

`GET /collections`.

### `status`

Config local mais `GET /health` no host REST.

### `mcp [--token vbm_…] [--url <mcp-url>]`

Proxy MCP stdio ↔ HTTP. `@valorbrain/connect` é este comando empacotado à
parte, para que clientes stdio possam rodar:

```json
{
  "mcpServers": {
    "valorbrain": {
      "command": "npx",
      "args": ["-y", "@valorbrain/connect", "--token", "vbm_…"]
    }
  }
}
```

O prefixo do token MCP é `vbm_`, não `vb_agent_`. Misture os dois e o host
MCP vai te rejeitar.

### `help [--json]`

Texto para humanos, ou a superfície de máquina.

## Self-hosting

```bash
npx @valorbrain/cli --url https://your-engine.example.com init --agent
```

Não existe instalador público de uma linha para o engine. On-prem é
acompanhado.
