## Respostas sem código

Alguns portões ainda respondem só com uma mensagem fixa no campo `error`. A mensagem é estável e pode ser comparada literalmente.

| Código | HTTP | Superfície | Causa | O que fazer |
|---|---|---|---|---|
| `Unauthorized` | 401 | REST | REST sem bearer, ou com uma credencial que não é do REST (`fk_`, segredo de administração). | Envie `Authorization: Bearer vbm_…` (ou a `vb_agent_` da conta). |
| `Unauthorized: admin secret required` | 401 | REST | Rota de administração da plataforma. | Não é rota de cliente; use as rotas públicas do REST. |
| `Forbidden: admin credential required for money routes` | 403 | REST | Rota de crédito ou assinatura chamada com token de tenant. | Não é rota de cliente; planos se mudam pelo app. |
| `Forbidden: /metrics is served only to local scrapers` | 403 | REST | `/metrics` fora da rede local e sem o token de métricas. | Não é rota de cliente. |
| `Rate limit exceeded — please slow down` | 429 | REST | Limite por credencial (ou por IP, em rota pública) estourado. | Aguarde `retry_after_ms` e reduza a cadência. |
