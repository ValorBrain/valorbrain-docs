## OpenAPI — two files, do not confuse them

| URL | What it actually is |
|---|---|
| `https://valorbrain.valor.digital/openapi.json` | SaaS **discovery** document. **4 paths** (ingest, device code, health-class). ~6.7 KB. |
| `https://docs.valor.digital/openapi.json` | Engine OpenAPI, regenerated at docs build (servers rewritten to valorbrain-api). |
| Engine repo `docs/reference/openapi.yaml` | Full engine spec. **116 paths**, including ops/graph. Not published on `valorbrain-api` (that host 404s `/openapi.json`). |

The 4-path file is real and useful for agent discovery on the marketing
host. It is not a description of `/search`. Use this site and the REST
page for integration.
