## Hosted vs self-hosted

**Hosted (start here):** no engine on your laptop. The harness talks to
`mcpbrain` with a `vbm_` token, or to REST with a `vb_agent_` key from the
CLI.

**Self-hosted:** you run the engine. Same tools, your infrastructure.
Enterprise on-prem is accompanied by our team — there is no public `docker
compose up` for the full GPU stack. [What Enterprise includes](https://valorbrain.valor.digital/en/enterprise).

## The quality loop (every harness)

1. **Consult before answering** — memory is authoritative about the
   operation; training data is not.
2. **Declare what you used** — `memory_used` with the docids you relied on.
   When the human confirms or corrects, pass `verdict`.

If a README tells you to run `valorbrain setup harness <name>`, that
subcommand is **not** on the published CLI. Use the page for that harness
instead.
