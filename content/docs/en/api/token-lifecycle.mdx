## Agent account key (`vb_agent_`) [#agent-key]

| Validity | Revocation | Rotation |
|---|---|---|

## Transient values

Short-lived values a flow hands out on the way to a credential. They are not credentials and authenticate no route.

| Credential | Issued by | Validity | Use |
|---|---|---|---|
| Claim code (OTP) | `POST /api/v1/agents/claim` | 10 minutes, up to 5 attempts | `POST /api/v1/agents/claim/verify` with the workspace's `vb_agent_` |
| OAuth authorization code | `GET /oauth/authorize → consentimento` | Single use, minutes | `POST /oauth/token` with the PKCE `code_verifier` |
