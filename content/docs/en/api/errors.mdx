Match on the code, not the text. The code comes in the JSON `error` (or `code`) field, in an OAuth redirect's `?error=` or in `WWW-Authenticate`'s `error=`. An engine test guarantees every code the server returns is on this list.

## Answers without a code

Some gates still answer with a fixed message in the `error` field. The message is stable and can be compared literally.

| Code | HTTP | Surface | Cause | What to do |
|---|---|---|---|---|
| `Unauthorized` | 401 | REST | REST without a bearer, or with a credential that is not for REST (`fk_`, admin secret). | Send `Authorization: Bearer vbm_…` (or the account's `vb_agent_`). |
| `Unauthorized: admin secret required` | 401 | REST | Platform administration route. | Not a client route; use the public REST routes. |
| `Forbidden: admin credential required for money routes` | 403 | REST | Credit or subscription route called with a tenant token. | Not a client route; change plans in the app. |
| `Forbidden: /metrics is served only to local scrapers` | 403 | REST | `/metrics` from outside the local network without the metrics token. | Not a client route. |
| `Rate limit exceeded — please slow down` | 429 | REST | Per-credential (or per-IP, on a public route) limit exceeded. | Wait `retry_after_ms` and slow down. |
