ValorBrain is **not** a chatbot and **not** an agent orchestrator. It is the
place your company keeps truth: decisions, incidents, people, keyed facts,
and the context an agent needs before it answers.

Two products share one mental model:

- **Hosted** — `valorbrain.valor.digital` (app) + `valorbrain-api.valor.digital` (REST) + `mcpbrain.valor.digital` (MCP).
- **On-prem (Enterprise)** — the same engine running on your network, deployed and operated together with our team. It is not a self-service installer: [see what Enterprise includes](https://valorbrain.valor.digital/en/enterprise) The architecture of what gets deployed is in the [on-premise guide](/en/docs/guides/on-prem).

## What you get

| Surface | What it is for |
|---|---|
| **CLI** `@valorbrain/cli` | Agent signup, MCP stdio proxy, `add`, `search`. Zero npm dependencies. Node 18+. |
| **MCP** | The working set agents actually call: retrieve, prepare, store, used, curate. |
| **REST** | Same capabilities over HTTP for any language. |
| **App** | Humans: onboarding, tokens, connectors, billing. |

Text is stored **verbatim**. A sentence written in Portuguese is retrieved in Portuguese. That is a product choice, not an accident.

## Hosts (read this once)

| Host | Role |
|---|---|
| `valorbrain-api.valor.digital` | REST. Search, documents, agent signup. |
| `mcpbrain.valor.digital` | MCP only. Non-OAuth REST on this host returns 401. |
| `valorbrain.valor.digital` | SaaS app, ingest with `fk_` keys, marketing, discovery. |
| `docs.valorbrain.com.br` | This site. (`docs.valor.digital` redirects here.) |

Do not send `/search` or `/documents` to `mcpbrain`. The engine treats every non-OAuth path on that host as MCP transport.

## For agents reading this page

The human usually sends: "Connect ValorBrain as your memory: read [https://valorbrain.com.br/connect.md](https://valorbrain.com.br/connect.md) and follow it."

1. If you have no account: run `npx -y @valorbrain/cli@latest init --agent --agent-caller <agent-name> --json`. Use the `mcp_token` (`vbm_…`) on MCP and the `api_key` (`vb_agent_…`) on REST only.
2. Connect your MCP client with the command from the [Quickstart](/en/docs/quickstart#2-connect-your-mcp-client) and call `memory_prepare`.
3. Prefer `help --json` over guessing subcommands. The published CLI does **not** have `setup harness`.
4. After you retrieve, call `memory_used` with the docids you actually relied on.
5. Full machine index: [`/llms.txt`](/llms.txt) · complete dump: [`/llms-full.txt`](/llms-full.txt).
