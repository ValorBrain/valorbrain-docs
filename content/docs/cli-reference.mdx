## Comandos

### init

create an agent account (REST key + MCP token) or claim it with an email

```
npx -y @valorbrain/cli init --agent [--agent-caller <platform>] [--force]
npx -y @valorbrain/cli init --email <address> [--otp <code>]
```

### identify

idempotent agent_caller backfill

```
npx -y @valorbrain/cli identify <platform>
```

### add

store a memory

```
npx -y @valorbrain/cli add <text> [--file <path>] [--collection <name>] [--title <t>] [--type <t>]
```

### search

search memories

```
npx -y @valorbrain/cli search <query> [--collection <name>] [--mode auto|keyword|semantic|hybrid]
```

### list

list collections

```
npx -y @valorbrain/cli list
```

### status

local config + remote health

```
npx -y @valorbrain/cli status
```

### mcp

stdio ⇄ HTTP MCP proxy

```
npx -y @valorbrain/cli mcp [--token vbm_…] [--url <mcp-url>]
```

### help

this surface, machine-readable with --json

```
npx -y @valorbrain/cli help [--json]
```
