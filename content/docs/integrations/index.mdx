## Hospedado vs self-hosted

**Hospedado (comece por aqui):** nenhum engine na sua máquina. O harness fala
com o `mcpbrain` com um token `vbm_`, ou com a REST com uma chave `vb_agent_`
vinda da CLI.

**Self-hosted:** você roda o engine. Mesmas ferramentas, sua infraestrutura.
O on-prem Enterprise é acompanhado pela nossa equipe — não existe um `docker
compose up` público para o stack GPU completo. [O que o Enterprise inclui](https://valorbrain.valor.digital/enterprise).

## O loop de qualidade (todo harness)

1. **Consulte antes de responder** — a memória manda na operação; os dados de
   treino, não.
2. **Declare o que você usou** — `memory_used` com os docids em que você se
   apoiou. Quando o humano confirmar ou corrigir, passe `verdict`.

Se um README mandar rodar `valorbrain setup harness <name>`, esse subcomando
**não** existe na CLI publicada. Use a página daquele harness.
