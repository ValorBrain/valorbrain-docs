---
title: OpenClaw
description: Plugin de slot memory com injeção por turno e extração no fim da sessão.
---

O OpenClaw integra como um plugin `kind: memory`: injeção de contexto por
turno e extração no fim da sessão. Os hooks de ciclo de vida existem para o
modelo não precisar lembrar de chamar o retrieve.

**Hospedado:** MCP via `@valorbrain/connect` ou HTTP para o `mcpbrain`, como
qualquer editor.

O README público do harness ainda diz `valorbrain setup openclaw`. Esse
subcomando **não** existe no `@valorbrain/cli@0.1.0`. Use MCP + o plugin da
árvore do engine quando você faz self-host; use o caminho MCP hospedado
quando não faz.

```bash
npx @valorbrain/cli init --agent --agent-caller unspecified
```

Passe uma string de caller estável que você vá reutilizar (`openclaw` serve).
