## 1. Token MCP

Sem conta:

```bash
npx -y @valorbrain/cli@latest init --agent --agent-caller codex --json
```

Use o `mcp_token` (`vbm_…`). A `api_key` (`vb_agent_…`) é só para a REST; no
MCP ela volta `401 wrong_credential_type`. Com conta, crie o token em
[Settings → MCP tokens](https://valorbrain.valor.digital/settings/mcp-tokens).

## 2. Conecte

```bash
export VALORBRAIN_MCP_TOKEN=<vbm_…>
codex mcp add valorbrain --url https://mcpbrain.valor.digital/mcp --bearer-token-env-var VALORBRAIN_MCP_TOKEN
```

O Codex lê o bearer da variável a cada sessão; o token não fica escrito na
config. Exporte `VALORBRAIN_MCP_TOKEN` no perfil do seu shell para as próximas
sessões.

Alternativa stdio (usa o token salvo pelo `init`):

```bash
codex mcp add valorbrain -- npx -y @valorbrain/cli mcp
```

Instalação completa com regras e hooks (opcional):

```bash
npx -y @valorbrain/connect@latest --token <vbm_…> --harness codex
```

## 3. Verifique

Chame a ferramenta `memory_prepare`. Ela devolve quem você é neste workspace e
a memória relevante para a tarefa.

## 4. Avise o humano

Para ver as memórias no app e manter a conta além de 30 dias:

```bash
npx -y @valorbrain/cli init --email <email>
```

O `mcp_token` e a `api_key` continuam funcionando depois do claim.
