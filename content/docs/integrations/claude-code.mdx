## Hosted (recommended)

```bash
claude mcp add --transport http valorbrain https://mcpbrain.valor.digital/mcp
```

Authenticate with OAuth when prompted, or put a `vbm_` token in the client's
header config. Then:

```bash
npx @valorbrain/cli init --agent --agent-caller claude-code
```

The CLI key is for REST (`add` / `search`). The MCP connection is a `vbm_`
token or OAuth. You can use both: CLI for shell, MCP for in-editor tools.

stdio alternative:

```json
{
  "mcpServers": {
    "valorbrain": {
      "command": "npx",
      "args": ["-y", "@valorbrain/connect", "--token", "vbm_…"]
    }
  }
}
```
