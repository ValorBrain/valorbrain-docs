## 1. Token MCP

Sem conta:

```bash
npx -y @valorbrain/cli@latest init --agent --agent-caller claude-code --json
```

Use o `mcp_token` (`vbm_…`). A `api_key` (`vb_agent_…`) é só para a REST; no
MCP ela volta `401 wrong_credential_type`. Com conta, crie o token em
[Settings → MCP tokens](https://valorbrain.valor.digital/settings/mcp-tokens).

## 2. Conecte

```bash
claude mcp add --transport http --scope user valorbrain https://mcpbrain.valor.digital/mcp --header "Authorization: Bearer <vbm_…>"
```

Alternativa stdio (usa o token salvo pelo `init`):

```bash
claude mcp add --scope user valorbrain -- npx -y @valorbrain/cli mcp
```

Instalação completa com regras e hooks (opcional):

```bash
npx -y @valorbrain/connect@latest --token <vbm_…> --harness claude-code
```

**claude.ai / Claude Desktop** não usam este comando: Settings → Connectors →
Add custom connector → URL `https://mcpbrain.valor.digital/mcp`, login por
OAuth.

## 3. Verifique

Chame a ferramenta `memory_prepare`. Ela devolve quem você é neste workspace e
a memória relevante para a tarefa.

## 4. Avise o humano

Para ver as memórias no app e manter a conta além de 30 dias:

```bash
npx -y @valorbrain/cli init --email <email>
```

O `mcp_token` e a `api_key` continuam funcionando depois do claim.

## Shell e editor juntos

A `api_key` que o `init` salvou serve para a REST pela CLI (`add` /
`search`). O MCP usa o `vbm_`. Você pode usar os dois: CLI no shell, MCP para
as ferramentas dentro do editor.

## O contrato que instalamos

A instalação completa (`@valorbrain/connect`) escreve no arquivo de
instruções do Claude Code um bloco gerenciado com o loop de qualidade:
consulte o ValorBrain antes de responder perguntas operacionais; chame
`memory_used` depois.

## Primeiras ferramentas

`memory_prepare` → trabalho → `memory_store` para qualquer coisa durável →
`memory_used`.
