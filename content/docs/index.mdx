ValorBrain **não** é um chatbot e **não** é um orquestrador de agentes. É o
lugar onde sua empresa guarda a verdade: decisões, incidentes, pessoas, keyed
facts e o contexto que um agente precisa antes de responder.

Dois produtos compartilham o mesmo modelo mental:

- **Hosted** — `valorbrain.valor.digital` (app) + `valorbrain-api.valor.digital` (REST) + `mcpbrain.valor.digital` (MCP).
- **On-prem (Enterprise)** — o mesmo engine rodando na sua rede, implantado e operado junto com o nosso time. Não é um instalador self-service: [veja o que o Enterprise inclui](https://valorbrain.valor.digital/enterprise) A arquitetura do que é implantado está no guia de [on-premise](/docs/guides/on-prem).

## O que você recebe

| Superfície | Para que serve |
|---|---|
| **CLI** `@valorbrain/cli` | Signup de agente, proxy MCP stdio, `add`, `search`. Zero dependências npm. Node 18+. |
| **MCP** | O conjunto de trabalho que os agentes realmente chamam: retrieve, prepare, store, used, curate. |
| **REST** | As mesmas capacidades por HTTP, para qualquer linguagem. |
| **App** | Humanos: onboarding, tokens, connectors, billing. |

O texto é armazenado **verbatim**. Uma frase escrita em português é recuperada em português. É uma escolha de produto, não um acidente.

## Hosts (leia isto uma vez)

| Host | Papel |
|---|---|
| `valorbrain-api.valor.digital` | REST. Busca, documentos, cadastro de agente. |
| `mcpbrain.valor.digital` | Só MCP. REST não-OAuth neste host devolve 401. |
| `valorbrain.valor.digital` | App SaaS, ingest com chaves `fk_`, marketing, discovery. |
| `docs.valorbrain.com.br` | Este site. (`docs.valor.digital` redireciona para cá.) |

Não envie `/search` ou `/documents` para o `mcpbrain`. O engine trata todo path não-OAuth naquele host como transporte MCP.

## Para agentes lendo esta página

O humano normalmente manda: "Conecte o ValorBrain como sua memória: leia [https://valorbrain.com.br/connect.md](https://valorbrain.com.br/connect.md) e siga as instruções."

1. Se você não tem conta: rode `npx -y @valorbrain/cli@latest init --agent --agent-caller <agent-name> --json`. Use o `mcp_token` (`vbm_…`) no MCP e a `api_key` (`vb_agent_…`) só na REST.
2. Conecte seu cliente MCP com o comando do [Começo rápido](/docs/quickstart#2-conecte-o-cliente-mcp) e chame `memory_prepare`.
3. Prefira `help --json` a adivinhar subcomandos. A CLI publicada **não** tem `setup harness`.
4. Depois de recuperar, chame `memory_used` com os docids em que você realmente se apoiou.
5. Índice completo para máquinas: [`/llms.txt`](/llms.txt) · dump completo: [`/llms-full.txt`](/llms-full.txt).
