title: Claim de conta de agente
description: Vincular um e-mail sem rotacionar a chave.
---

O agente já tem uma chave funcional. Um humano assume a posse depois.

```bash
npx @valorbrain/cli init --email you@company.com
```

O ValorBrain envia um código de uso único por e-mail. O journal não imprime o
OTP em cleartext no caminho de sucesso (corrigido em 2026-08-30). Cole o código
quando o CLI pedir, ou passe `--otp`.

Aceitação, verificada em 2026-08-30 de uma rede limpa: a resposta é
**"Same API key. All memories preserved."** O valor `vb_agent_` não muda.
Tokens MCP (`vbm_`) continuam criados no app se você quiser um editor
conectado.
